Notes & Known Quirks

CII — internal_url regex stops at the domain. https://intranet.testleaf.com/roadmap masks only the domain, leaving /roadmap exposed. Rule pattern has no path-segment matching; present since Phase 6, not introduced by this test run.
Toxic — naive substring matching produces false positives. Keyword "hell" matches inside "Hello" because detection uses text.includes() with no word-boundary check. Observed live during the Phase 13 /api/moderate run.
Winston file transport is buffered. Force-killing the dev server (taskkill /F) immediately after a request can truncate logs/moderation.log before the write flushes. Re-verified with a graceful pause before shutdown — logging itself is correct, this is an artifact of how the test session tears the server down.
Hot-reload confirmed under this run too. Config loader keys its cache on file mtime, so rule edits apply on the next request with no server restart.
